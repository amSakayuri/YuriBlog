# 内容创作

## 文章与散文

1. 在对应栏目新建内容，填写标题、slug（网址中的名称）、简介及正文。
2. 保存草稿，点击预览查看效果。
3. 设置标签、分类、封面及语言。
4. 状态改为 `PUBLISHED` 并保存，即可公开。

首次手动保存草稿后，停止输入 4 秒会自动保存；已发布内容不自动保存。定时发布选择 `SCHEDULED` 和未来时间，服务器需保持 worker 运行。发布后无需重新部署网站。

slug 修改会改变链接，也可能影响已有评论的匹配，请尽量保持稳定。

## Markdown

支持标题、列表、引用、表格、图片、链接、代码和数学公式；不执行 JavaScript 或原始 HTML。

```markdown
## 小节标题

普通正文与 **粗体**、_斜体_、~~删除线~~、`行内代码`。

![图片描述](/uploads/媒体库生成的文件名.webp)

行内公式 $E=mc^2$。
```

代码块使用三反引号和语言名称，例如 typescript、python。H2–H4 自动生成目录；正文图片可点击放大，按 Escape 关闭。图片建议从媒体库复制链接，或在编辑器上传插入。

## 导入 Markdown 文件

文章、散文、小说列表或小说章节管理中点击“导入Markdown”，选择 UTF-8 的 `.md` 或 `.markdown` 文件，大小不超过 2 MB。始终导入为草稿，同 slug 不覆盖。

小说列表导入会创建独立小说，并把正文保存为首章草稿；默认首章标题取正文 H1 或文件名，slug 为 `chapter-1`，可用 front matter 的 `chapterTitle`、`chapterSlug` 指定。不按标题自动拆章。已有小说请在章节管理中导入，新章节排在末尾、默认未分卷，之后可编辑所属卷。散文直接导入正文草稿。

可在正文前添加以下信息：

```yaml
---
title: 文章标题
slug: article-slug
description: 文章摘要
language: zh
tags: [TypeScript, 开发笔记]
category: 技术
---
```

未填写标题时，从正文 H1 或文件名提取。相对路径图片不会自动上传，导入后检查图片链接再发布。

## 小说

在“小说”中新建作品，设置简介、封面和创作状态，再管理卷与章节。章节可排序、移动到其他卷，并单独保存草稿或发布。

公开阅读要求：小说不是 `DRAFT`，章节为 `PUBLISHED` 且已到发布时间。

章节关系由作者手动选择来源、目标和类型，可填写说明，在关系图与关系列表中展示。删除关系不会删除章节。

阅读器支持字号、行距、宽度、缩进及明暗/护眼主题。阅读进度保存在读者浏览器中，不上传服务器。

## 中英文与订阅

中文选 `zh`，英文选 `en`。同一内容的两个译本设置相同 `translationKey`，各自编辑、发布；系统不会自动翻译。

网站 RSS 图标打开 `/rss`，可分别订阅：

| 类型                                   | 中文              | 英文                 |
| -------------------------------------- | ----------------- | -------------------- |
| 杂谈（技术文章等）                     | `/feed.xml`       | `/en/feed.xml`       |
| 文学作品（散文、小说及已发布章节更新） | `/works/feed.xml` | `/en/works/feed.xml` |

将对应完整网址添加到 RSS 阅读器即可。文学订阅只包含公开内容，小说草稿及其章节、章节草稿和未来发布的内容不会出现；已有条目更新保持相同链接。
